nxova-opn-repo - OPNsense 软件源

基于域名的分流套件：mosdns DNS 分流 -> pf 表 -> 策略路由 -> xray-core 出口。各插件独立启停。

在 OPNsense 上添加软件源

fetch -o /usr/local/etc/pkg/repos/nxova-opn.conf https://opnrepo.zro.qzz.io/nxova-opn.conf
pkg update -r nxova-opn
pkg install -r nxova-opn os-mosdns os-xray os-tun2socks

包含内容

  • os-mosdns - mosdns DNS 分流引擎（规则组：直连/代理/阻止），随包带 mosdns-pf 二进制与 pf-aliasd（解析结果同步进 pf 表，默认表名 proxy_group）
  • os-xray - xray-core 管理（节点/订阅/入站/路由规则），配置与服务独立命名，与官方包零冲突
  • os-tun2socks - tun2socks 透明桥，把策略路由流量送进本地 SOCKS5

版本格式 <构建日期>.<CI 轮次>（如 2026.10.23.31），CI 推送后自动打包发布，pkg upgrade -r nxova-opn 直接升级。源码与说明：github.com/nxovaeng/nxova-opn-repo
