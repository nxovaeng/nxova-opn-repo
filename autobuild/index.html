nxova-opn-repo - OPNsense 软件源

mosdns DNS 分流 (mosdns -> pf 表 -> 策略路由) 插件与配套守护进程。

在 OPNsense 上添加软件源

cat > /usr/local/etc/pkg/repos/nxova-opn.conf <<'EOF'
nxova-opn: {
  url: "https://opnrepo.zro.qzz.io",
  enabled: yes
}
EOF
pkg update -r nxova-opn
pkg install -r nxova-opn os-mosdns

包含内容

  • os-mosdns - MosDNS 原生 MVC 插件 (Services -> MosDNS -> Settings)
  • /usr/local/bin/mosdns - mosdns-pf fork (含 pf_alias 插件)，随包安装
  • /usr/local/bin/pf-aliasd - pf 表同步守护进程，随包安装

安装后在 WebUI 里启用两个服务，旧 mosdns-controller 如在运行请先停掉。
